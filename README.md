# PlaylistClock

Free playlist length calculator: total runtime, track count and average from pasted tracklists, plus a slot planner. No signup.

## Features
- Paste mode: drop a whole tracklist, times auto-extracted, titles kept
- Gap adder for announcements/applause/crossfade-aware totals
- Slot Planner: enter minutes + average song length, get the track count
